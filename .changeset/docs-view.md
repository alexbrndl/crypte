The shell has a docs view. Every component has a page there, with its status, owner, Figma link and stories, plus its markdown guidelines when it has some; general markdown pages sit beside them by path. A Links panel shows a page's stories, the tokens its component reads and the pages that cite it. In the stories tree a component's label now only folds it, and an eye at the end of its row opens its docs page.
