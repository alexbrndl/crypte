# @crypte/core

The protocol Crypte's packages share: the story format, the manifest, the channel between the shell and the preview, and the plugin contract. You do not install it: `@crypte/cli` and the adapters bring it, and a plugin of your own imports its types from `@crypte/cli`.

See the repository for the whole picture: https://github.com/alexbrndl/crypte. Version `0.x`: no stability promise yet.
