# @crypte/vue

The Vue adapter of Crypte: `defineStories` for your story files, and `vue()` for `crypte.config.ts`, beside `@vitejs/plugin-vue` in `vite.plugins`.

```sh
npm i -D @crypte/cli @crypte/vue @vitejs/plugin-vue
```

See the repository for the whole picture: https://github.com/alexbrndl/crypte. Version `0.x`: no stability promise yet.
