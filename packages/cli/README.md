# @crypte/cli

The `crypte` command: a design system workshop that stays light, drawn from your stories.

```sh
npm i -D @crypte/cli @crypte/react   # or @crypte/vue @vitejs/plugin-vue
npx crypte init
npx crypte dev
```

Commands: `dev`, `build`, `check`, `init`, `mcp` and `visual`. A configuration with no `plugins` key turns on `@crypte/controls`, `@crypte/tokens`, `@crypte/source` and `@crypte/actions`, which come with it.

See the repository for the whole picture: https://github.com/alexbrndl/crypte. Version `0.x`: no stability promise yet.
